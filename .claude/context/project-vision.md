# Project Vision

## Goal

Become the ScamShield of Malaysia — a trusted, community-driven scam protection platform.

## Phase 1: Viral MVP

- Shareable verdict cards drive organic growth via WhatsApp and Telegram
- "Safe Anot?" becomes the reflex action when receiving suspicious links
- Free, no sign-up required — minimize friction to adoption
- Target: 10K downloads in first 3 months

## Phase 2: Family Guardian

- Family members can pair devices and monitor each other's security status
- Push notifications for new scam campaigns targeting MY/SG
- Gamification: streaks for regular security audits
- Target: 50K downloads, 5K DAU

## Phase 3: Data Moat

- Community scam reporting feeds back into the database
- Data partnerships with banks, telcos, MCMC (Malaysian regulator)
- Premium features: advanced alerts, priority scanning, family dashboard
- Monetization: freemium model, B2B data licensing
- Target: 100K+ downloads, sustainable revenue

## Competitive Positioning

| Competitor | Gap We Fill |
|-----------|------------|
| ScamShield (SG) | Government-run, SG-only, no community |
| Google Safe Browsing | Generic, no MY/SG-specific data |
| Norton/McAfee | Expensive, bloated, not mobile-first |
| None (MY) | No dedicated scam checker exists for Malaysia |
