## Issue E02-002: Daily Database Sync (WorkManager)

### Tasks
1. File: `android/app/src/main/java/com/safeanot/app/data/remote/SafeAnotApi.kt`
   Action: Create
   Details: Retrofit interface with endpoints: `@GET("api/data/latest") suspend fun getLatestMetadata(): LatestMetadataResponse`, `@GET("api/data/full") @Streaming suspend fun getFullDatabase(): ResponseBody`, `@GET("api/data/delta") @Streaming suspend fun getDelta(@Query("since") since: String): ResponseBody`, `@GET("api/data/bloom") @Streaming suspend fun getBloomFilter(): ResponseBody`, `@POST("api/check") suspend fun checkDomain(@Body request: CheckRequest): CheckResponse`.

2. File: `android/app/src/main/java/com/safeanot/app/data/remote/model/ApiModels.kt`
   Action: Create
   Details: Data classes: `LatestMetadataResponse` (version, full_key, delta_key, bloom_key, full_size_kb, delta_size_kb, bloom_size_kb, sqlite_size_kb, domain_count, build_timestamp), `CheckRequest` (url/domain), `CheckResponse` (domain, verdict, reason, confidence, details).

3. File: `android/app/src/main/java/com/safeanot/app/domain/repository/SyncRepository.kt`
   Action: Create
   Details: Interface: `suspend fun syncDatabase(): Result<Unit>`, `suspend fun getLastSyncVersion(): String?`, `suspend fun isFirstRun(): Boolean`.

4. File: `android/app/src/main/java/com/safeanot/app/data/repository/SyncRepositoryImpl.kt`
   Action: Create
   Details: Orchestrate sync: 1) GET `/api/data/latest` → compare version. 2) If first run or >7 days old → GET `/api/data/full` → parse SQLite → bulk insert into Room. 3) Otherwise → GET `/api/data/delta` → parse JSON → apply adds/removes to Room. 4) GET `/api/data/bloom` → verify SHA-256 checksum from manifest → save to internal files dir. 5) Update metadata. All operations wrapped in Room transaction. On checksum mismatch → abort and retry on next cycle.

5. File: `android/app/src/main/java/com/safeanot/app/worker/DatabaseSyncWorker.kt`
   Action: Create
   Details: `CoroutineWorker` that calls `SyncRepository.syncDatabase()`. Constraints: `NetworkType.UNMETERED` (WiFi), `requiresBatteryNotLow(true)`. Return `Result.retry()` on transient failure. Unique work name: `"safeanot_db_sync"`.

6. File: `android/app/src/main/java/com/safeanot/app/SafeAnotApp.kt`
   Action: Modify
   Details: Schedule `DatabaseSyncWorker` as `PeriodicWorkRequest` (24h, `ExistingPeriodicWorkPolicy.KEEP`). Also trigger immediate `OneTimeWorkRequest` on first run (when metadata is null).

7. File: `android/app/src/main/java/com/safeanot/app/di/NetworkModule.kt`
   Action: Create
   Details: Hilt module providing Retrofit instance, OkHttpClient, and `SafeAnotApi`. Base URL configurable via BuildConfig.

### Tests
- `android/app/src/test/java/com/safeanot/app/data/repository/SyncRepositoryImplTest.kt` -- mock API and DAO to test: delta vs full fallback, checksum verification, transaction rollback on failure, first-run detection, metadata update
- `android/app/src/androidTest/java/com/safeanot/app/worker/DatabaseSyncWorkerTest.kt` -- verify worker constraints (UNMETERED network, battery), unique work policy

### Acceptance Criteria
- Sync worker runs daily with `NetworkType.UNMETERED` and `requiresBatteryNotLow` constraints
- Uses `ExistingPeriodicWorkPolicy.KEEP` with unique name `"safeanot_db_sync"`
- Exponential backoff on transient failure via `Result.retry()`
- Local DB is updated with delta changes from backend (adds/removes applied in transaction)
- Full DB download occurs if first run or local version is >7 days old
- Bloom filter SHA-256 checksum verified against manifest before saving
- Sync is idempotent — running twice with same version is a no-op

## Issue E02-003: Link Check Flow (3-Layer Architecture)

### Tasks
1. File: `android/app/src/main/java/com/safeanot/app/util/UrlNormalizer.kt`
   Action: Create
   Details: Normalize URLs: lowercase, strip protocol/path/query/fragment/www. Handle Punycode/IDN via `java.net.IDN.toASCII()`. Extract registerable domain using hardcoded two-part TLD list (com.my, com.sg, co.uk, etc.) — no external PSL library needed for v1, just the ~20 TLDs relevant to MY/SG. Validate format: reject IPs, localhost, consecutive dots, leading/trailing hyphens.

2. File: `android/app/src/main/java/com/safeanot/app/domain/model/LinkVerdict.kt`
   Action: Create
   Details: Data class: `domain: String`, `verdict: Verdict` (enum: SAFE, SUSPICIOUS, DANGEROUS, UNKNOWN, NOT_IN_DATABASE), `reason: String`, `confidence: Float`. `NOT_IN_DATABASE` is used when Bloom filter says "definitely not scam" — shown to user as "Not in our database. Proceed with caution."

3. File: `android/app/src/main/java/com/safeanot/app/domain/repository/LinkCheckRepository.kt`
   Action: Create
   Details: Interface: `suspend fun checkLink(input: String): LinkVerdict`.

4. File: `android/app/src/main/java/com/safeanot/app/data/repository/LinkCheckRepositoryImpl.kt`
   Action: Create
   Details: 3-layer implementation: 1) Normalize domain. 2) Room query → if found, return verdict. 3) Bloom filter `mightContain` → if false, return NOT_IN_DATABASE. 4) If Bloom positive → POST `/api/check` → cache result in Room (with 24h TTL via `cachedAt` timestamp) → return verdict. Handle offline gracefully: if API unreachable and Bloom positive, return UNKNOWN with reason "Unable to verify — check your connection."

5. File: `android/app/src/main/java/com/safeanot/app/domain/usecase/CheckLinkUseCase.kt`
   Action: Create
   Details: Thin wrapper: normalize input, call repository, return result. Validates input is non-empty.

### Tests
- `android/app/src/test/java/com/safeanot/app/util/UrlNormalizerTest.kt` -- exhaustive test fixtures: protocols, paths, queries, fragments, www, uppercase, Punycode/IDN, two-part TLDs (maybank2u.com.my), IPs (rejected), localhost (rejected), consecutive dots (rejected), leading/trailing hyphens (rejected)
- `android/app/src/test/java/com/safeanot/app/data/repository/LinkCheckRepositoryImplTest.kt` -- mock DAO, BloomFilter, API: test all 3 layers, cache write after API hit, offline fallback, 24h cache TTL expiry
- `android/app/src/test/java/com/safeanot/app/domain/usecase/CheckLinkUseCaseTest.kt` -- test empty input, valid URL, domain-only input

### Acceptance Criteria
- Local DB hits resolve in <10ms
- Bloom filter correctly gates API calls (no API call if Bloom filter is negative)
- Bloom filter positive + API unreachable → UNKNOWN with connection message
- API results cached in Room with 24h TTL (re-checked after expiry)
- Punycode/IDN domains normalized via `java.net.IDN`
- Domain validation rejects IPs, localhost, malformed hostnames
