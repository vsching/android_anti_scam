## Issue E03-002: Install Source Detection

### Tasks

7. File: `android/app/src/main/java/com/safeanot/app/domain/model/AuditStatus.kt`  
   Action: Modify  
   Details: Keep existing user-facing statuses unchanged while mapping `NOT_QUERYABLE` detection to review-required behavior with explicit explanation text.

### Tests
- `android/app/src/test/java/com/safeanot/app/data/repository/AuditRepositoryImplTest.kt` - installed vs not installed vs not queryable mapping, state preservation, scan timing guard.
- `android/app/src/test/java/com/safeanot/app/util/PackageCheckerTest.kt` - exception-to-state mapping and fallback icon/label behavior.
- `android/app/src/androidTest/java/com/safeanot/app/data/local/AuditDaoTest.kt` - persistence for `risk_description` + `detection_state`.

### Acceptance Criteria
- All packages in technical requirements list are scanned.
- Detection uses `PackageManager.getPackageInfo()` with robust exception handling.
- Installed/not-installed/not-queryable states are represented consistently.
- App icons are loaded for installed apps; fallback shown otherwise.
- Detection path measured and optimized for <500ms across tracked package list.

   Action: Modify

### Tests

### Acceptance Criteria

9. File: `android/app/src/main/java/com/safeanot/app/worker/AuditReminderScheduler.kt`  
   Action: Create

10. File: `android/app/src/main/java/com/safeanot/app/SafeAnotApp.kt`  
    Action: Modify  
    Details: Delegate audit reminder scheduling bootstrapping to `AuditReminderScheduler` and load persisted config at startup.

11. File: `android/app/src/main/java/com/safeanot/app/feature/profile/ProfileViewModel.kt`  
    Action: Modify  
    Details: Replace in-memory toggle with repository-backed reminder settings updates that trigger scheduler refresh (enable/disable + interval changes).

### Tests
- `android/app/src/test/java/com/safeanot/app/data/repository/AuditReminderDiffTest.kt` - newly installed risky app detection, regression detection, no-change case.
- `android/app/src/test/java/com/safeanot/app/worker/AuditReminderSchedulerTest.kt` - interval mapping (3/7/14/30), enable/disable enqueue/cancel behavior.
- `android/app/src/androidTest/java/com/safeanot/app/worker/AuditReminderWorkerTest.kt` - notification posted only on detected change, notification intent opens dashboard.
- `android/app/src/androidTest/java/com/safeanot/app/feature/profile/ReminderSettingsIntegrationTest.kt` - UI toggle persists and updates scheduled work.

### Acceptance Criteria
- Periodic worker runs at configured interval (default 7 days; options 3/7/14/30).
- Worker compares against last audit state before notifying.
- Notifications only fire for new risk/regression changes.
- Notification tap opens Shield dashboard.
- Reminder toggle and interval are persistent and user-controlled in settings.
- WorkManager constraints keep battery/Doze-friendly behavior.
